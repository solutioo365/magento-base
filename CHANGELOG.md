# Changelog

## 1.0.0 – 2026-08-05

- First public release of Solutioo Base for Magento 2 / Adobe Commerce
- Admin menu entry and ACL root for Solutioo extensions (inkl. Direktlink zur Config)
- Shared `ConfigProviderAbstract` helper
- Optional anonyme Nutzungsrückmeldung (Hostname + Modul-/Magento-Version; Demo-Module wie ThemeSwitcher ausgeschlossen)
- Admin-Gruppe „Unsere Apps & Lösungen“ mit Überblick zu Magento-, Shop-, Versand- und Business-Central-Apps (ein-/ausschaltbar)
